Android → Windows over local Wi-Fi

Transfer files from Android to Windows without a cloud detour.

LAN Send moves files, text, links and clipboard content directly between your Android phone and Windows PC over the same trusted local network.

A simpler phone-to-PC handoff.

Messaging apps and cloud drives can move files, but they usually add an upload, account or sync step. LAN Send is designed for the common case where your phone and PC are already nearby and connected to the same network.

Direct local transfer

Send supported content between paired devices over your local network instead of routing the transfer through RTEK Labs cloud infrastructure.

Two-way

Send Android → Windows or Windows → Android from the same paired setup.

Files, text and links

Move screenshots, documents, URLs, notes and clipboard text without creating a message to yourself.

No LAN Send account

Pair your devices by QR code. LAN Send does not require a separate LAN Send account to transfer.

How to transfer files from Android to Windows.

  1. Install LAN Send on the Windows PC and Android phone.
  2. Connect both devices to the same trusted local Wi-Fi/network.
  3. Open LAN Send on Windows and scan its QR code from the Android app.
  4. Select a file on Android and send it to the paired PC.
  5. The Windows app receives the file into its configured inbox.
