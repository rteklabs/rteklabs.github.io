Getting Started

Install, pair and start moving files between your Android phone and Windows PC. Most setups take only a couple of minutes.

1. Install and pair

  1. Install LAN Send on your Android device using the Android setup & download guide.
  2. Install the Windows companion on your PC.
  3. Connect the Android device and PC to the same local Wi‑Fi/network.
  4. Open LAN Send on Windows and display its pairing QR code.
  5. On Android, choose Add PC and scan the QR code.
  6. Once the PC shows online, you're ready to send.
Important — Windows network type: LAN Send is designed for trusted private networks such as your home or office Wi‑Fi. If Windows has classified the current network as Public, Windows Firewall may block incoming LAN Send connections to the PC. This can make the PC appear offline or prevent Android → Windows transfers. On a network you trust, set the Windows network profile to Private. Do not change an unfamiliar café, hotel, airport or other public Wi‑Fi network to Private just to make LAN Send work.

2. Send something

Android → Windows

Open LAN Send on Android, select your paired PC, choose the file or content you want to send, then send it. Received files are saved according to your Windows receive settings.

Windows → Android

Open LAN Send on Windows, choose your paired Android device and send a file or text. You can also use supported Windows sharing options such as Send with LAN Send.

Closed-test checklist

If you're helping test LAN Send, thank you. A useful test is short:

  1. Join the closed test using the Google account that will install the app.
  2. Install LAN Send from Google Play. If you previously installed a development/sideloaded Android build and Play cannot install the test build, uninstall the old LAN Send first.
  3. Install the Windows companion and pair by QR code.
  4. Send at least one file or text item Android → Windows.
  5. Send at least one file or text item Windows → Android.
  6. Close and reopen LAN Send and confirm your paired device reconnects.
Found a problem? Please include what you were doing, what you expected to happen, what happened instead, and whether the issue was on Android or Windows. Screenshots are helpful when available.

Troubleshooting

My PC shows offline

Confirm LAN Send is running on Windows and both devices are on the same local network. Reopen LAN Send on the PC and Android device and allow a moment for reconnection. If the PC still shows offline, check that Windows is using the Private network profile for this trusted network.

LAN Send works in one direction only

If Windows → Android works but Android → Windows does not, check the Windows network profile. LAN Send's Windows receiver is allowed through Windows Firewall on Private networks. If Windows considers the connection Public, incoming transfers to the PC may be blocked.

Both devices are on the same Wi‑Fi, but they still can't connect

Some guest, hotel, café, office and public Wi‑Fi networks use device isolation (also called client or AP isolation). This prevents devices on the same Wi‑Fi from communicating directly. LAN Send cannot bypass this network restriction. Try a trusted home/private network or another network that allows local device communication.

The QR code won't pair

Make sure you're scanning the current QR code shown by the Windows companion and that both devices can communicate on the same local network.

Google Play says LAN Send can't be installed

If this device previously had a sideloaded/development copy of LAN Send, uninstall that copy and install the closed-test version again from Google Play. Different signing certificates can prevent one build from replacing another.

Windows blocks or warns about the companion

The current direct Windows download is provided as a beta installer while the Microsoft Store release is being certified. If installation is blocked or Windows shows a security warning, contact RTEK Labs support rather than disabling Windows security protections.

FAQ

Does RTEK Labs upload or store my transferred files?

No. LAN Send is designed to transfer supported content directly between paired devices over your local network. RTEK Labs does not operate a cloud server that receives or stores those transfers.

Do I need an LAN Send account?

No. Device pairing is used instead of an LAN Send account.

Does LAN Send need the internet?

The transfer itself is designed for your local network. Internet access can still be required for things outside the transfer path, such as downloading or updating the apps through their distribution platforms.

Can I use LAN Send on public Wi‑Fi?

LAN Send is intended for trusted private networks. Public or guest Wi‑Fi may block direct communication between devices, and Windows may also block incoming LAN Send connections when the network is classified as Public. For reliability and security, use LAN Send on a trusted home or office network.

Can Android remember more than one PC?

Yes. LAN Send can remember up to three PCs so you can reconnect without pairing from scratch each time.
