LAN Send → Android

Android companion

Get LAN Send for Android

LAN Send transfers files, messages and clipboard content directly between Android and Windows over your local Wi-Fi network.

Install the Android app

Choose either Google Play closed testing or the direct signed APK.

Option 1 — Google Play closed testing

  1. Join the tester group.
    Join using the Google account you use on your Android phone.
  2. Become a tester.
    After joining the group, open the Google Play testing page and select Become a tester.
  3. Install LAN Send.
    Google Play will then provide access to the app. Access may occasionally take a short time to propagate.
1. Join tester group 2. Become a tester

Option 2 — Direct APK

If you cannot use the Google Play testing programme, you can install the signed LAN Send Android APK directly.

Your phone may ask you to allow installation from your browser or file manager. Only enable this for the installation source you trust.

Download Android APK

Current direct build: LAN Send 3.0.8

Pair Android with Windows

  1. Connect the Windows PC and Android phone to the same Wi-Fi network.
  2. Open LAN Send on Windows.
  3. Open LAN Send on Android.
  4. Choose Add PC and scan the QR code shown by Windows.
  5. Wait for both applications to show the device as online.
  6. Send a small test file.
Connection note: Guest Wi-Fi, corporate Wi-Fi or networks with client/AP isolation may prevent devices on the same Wi-Fi from communicating with each other.

For Microsoft Store certification testers

The LAN Send Windows application is a companion application for LAN Send on Android. Testing its primary file-transfer functionality requires an Android device and Windows PC connected to the same local network.

No LAN Send account or login credentials are required.

Microsoft certification staff may install the Android companion using either the Google Play closed-testing instructions above or the direct signed APK.
